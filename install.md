# Руководство по установке и первому запуску YuE2-3B Studio

## 1. Подготовка файлов репозитория

Убедитесь, что в корневой папке проекта находятся следующие файлы:
* `python.zip` — портативное окружение Python 3.11 со встроенным `pip`.
* `yue2_infer-0.1.5-py3-none-any.whl` — колесо инференса модели YuE2.
* `requirements.txt` — список всех зафиксированных зависимостей.
* `install.bat` — командный файл автоматической установки.
* `start_server.bat` — командный файл запуска веб-студии.
* `web_server.py` — серверная часть на Python.
* `index.html` — пользовательский веб-интерфейс.

---

## 2. Установка зависимостей (1 клик)

1. Запустите командный файл **`install.bat`**.
2. Скрипт автоматически:
   * Распакует архив `python.zip` в локальную подпапку `python\`.
   * Установит PyTorch 2.5.1 с поддержкой CUDA 12.1.
   * Установит необходимые звуковые и нотные библиотеки (`librosa`, `music21`, `soundfile`).
   * Установит локальное колесо `yue2_infer-0.1.5-py3-none-any.whl`.
3. Дождитесь надписи `[ГОТОВО] Все зависимости успешно установлены!` и нажмите любую клавишу для выхода.

---

## 3. Настройка токена Hugging Face (Обязательно)

Веса моделей YuE2 загружаются с платформы Hugging Face.

1. Зарегистрируйтесь на [HuggingFace.co](https://huggingface.co/) и получите бесплатный Read-токен в разделе [Settings -> Access Tokens](https://huggingface.co/settings/tokens).
2. Откройте файл **`start_server.bat`** в Блокноте (ПКМ -> «Изменить»).
3. Найдите строку:
   ```bat
   set HF_TOKEN=hf_ВАШ_ТОКЕН_ЗДЕСЬ
   ```
4. Замените hf_ВАШ_ТОКЕН_ЗДЕСЬ на ваш реальный токен Hugging Face (например: set HF_TOKEN=hf_abc123...) и сохраните файл.

5. Первый запуск
Дважды кликните по start_server.bat.

В браузере автоматически откроется страница:

Plaintext
[http://127.0.0.1:7860](http://127.0.0.1:7860)
При первой генерации сервер автоматически скачает веса модели m-a-p/YuE2-3B и вокодера YuE2-Vae в локальную папку models_cache\. После завершения загрузки начнется синтез звука.
